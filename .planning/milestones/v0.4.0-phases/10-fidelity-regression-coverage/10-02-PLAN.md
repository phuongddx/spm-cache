Bucket names are derived only from observed output.

Output: One new meta-spec (approx. 300-400 lines) + one JSON fixture, green under `bundle exec rspec spec/fidelity_bucket_partition_spec.rb`, with fail-first mutation proofs for both arms of the partition assertion.
