# Plan 12-02 — Core::Sh run-log sink + failure_detail restoration (SC2 subprocess capture)

<objective>
Make spawned xcodebuild/swift subprocess output reach the run log and restore error
detail on the live path. Two changes inside the single shell seam `Core::Sh`
(lib/spm_cache/core/sh.rb): (1) the popen3 branch gets per-stream sinks plus a bounded
per-stream tail so a failing live-mode command raises with the same 60-line

recorded as structured `sh` events in the active run log. No caller signatures change
(nil-disables everywhere); no second shell-out path is created.

output, so a failing build's error lines reconstruct offline. Also closes the
milestone-flagged discarded-capture gap (12-RESEARCH.md "Sh popen3 fix shape").

Output: modified lib/spm_cache/core/sh.rb, new spec/sh_run_log_sink_spec.rb.
