# Plan 12-01 — Tracer: end-to-end run-log slice (writer + Main.run wiring)

<objective>
Build the thinnest production-quality end-to-end slice of LOGS-01: any CLI run that
reaches `Command.run` through `SPMCache::Main.run` leaves a complete JSONL run log
(header / stream-tagged body / exit line) on disk, while terminal bytes and exit codes
stay byte-identical. This plan creates `Core::RunLog` (writer + tee wrappers + pre-scan)

CLI surface — the keystone every later plan (Sh sink, events, retention, watch cycles)
extends. It also fixes the process-wide `RunLog.current` seam later plans consume.

Output: `lib/spm_cache/core/run_log.rb`, modified `main.rb`/`config.rb`/`command.rb`,
two new spec files, all green in the full suite.
