## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → the three mutation endpoints | untrusted request bodies reaching a config writer and a process spawner |
| client-rendered disabled state → server permission | the browser's disabled attribute is decoration; the server must decide independently |
| request body → spawned argv | the classic command-construction boundary, crossed only through a frozen table |
| the spawn slot → concurrent mutations | one slot governs spawns; config writes deliberately bypass it |
