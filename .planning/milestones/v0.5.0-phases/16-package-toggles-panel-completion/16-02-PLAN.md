<objective>
Give TOGL-03's one unpersisted reason a real fact source: the lockfile enrichment that already runs
`swift package describe` for every package records, in the same pass and from the same output,
whether that package declares a binary target — and the lockfile can answer which table-row names a
binary-backed package covers.

Purpose: SC3 lists `binary-target` among the five reasons a package cannot be toggled. Every other
reason derives from something already on disk; this one derives from nothing, and shipping without
it would render binary-backed rows as freely toggleable — an invitation to break a project that has
no source to rebuild from.

Output: the derived flag written and invalidated with products[], and one lockfile reader that
resolves it to the names the cache-state table uses.
</objective>
