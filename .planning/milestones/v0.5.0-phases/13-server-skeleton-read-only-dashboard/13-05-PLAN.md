## Prefix decision: relative `assets/`, not absolute `/assets/` (fix-contract item 1)

Relative `assets/styles.css` etc. is the ONLY choice that fixes the refs without weakening a
locked pin:

1. spec/web_frontend_spec.rb:73 pins `(?:src|href)=["']/` MUST NOT match index.html — no leading
   slash in any ref value. An absolute `/assets/…` ref violates this verbatim and could only pass
   by weakening a locked negative pin (prohibited: fix the source, never the test).
2. The page is served only at document root '/': the router's root branch matches exactly '/'
   and '' (router.rb:74), single servlet. A relative ref against base '/' is unambiguous —
   URI.join('/', 'assets/app.js') → '/assets/app.js', exactly the existing route.
3. 13-CONTEXT.md "Frontend Architecture" and 13-03's shipped truth describe the dashboard as
   same-origin RELATIVE assets — the relative prefix is the form the phase already promised.
