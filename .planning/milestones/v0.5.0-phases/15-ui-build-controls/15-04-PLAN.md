## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (any origin) → POST /api/build, POST /api/rollback | two mutating endpoints, one of them destructive to project integration state |
| request body → scope whitelist → argv fragments | the only path from request data toward a command line |
| lock state on disk → 2xx envelope → dashboard row | derived project state leaving the server as advisory display data |
