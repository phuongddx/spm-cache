wrapping the installer returned from Command::Watch's injected installer_factory in a
cycle decorator — `Core::RunLog.cycle_wrapper` — that opens a fresh log, tees the
streams, sets RunLog.current (so the phase markers from Plan 12-04 and sh events from

in an ensure. `Core::Watcher` is not modified. The second task proves D-08's
no-allowlist property and records the A6 decision (legacy `use --watch` =
session-level) as specs.

family (`watch`) with per-cycle granularity so Phase 14 can relay each regeneration as
its own run, and SC3 (Main level correctly skips watch; inter-cycle narrative stays
terminal-only per D-09).

Output: modified run_log.rb + watch.rb, two extended spec files.
</objective>
