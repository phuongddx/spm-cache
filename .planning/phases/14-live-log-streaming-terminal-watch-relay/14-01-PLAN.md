<objective>
Build the thinnest production-quality end-to-end slice of live log streaming: one tailer thread
follows the shared runs dir, one broadcaster fans lines out to per-client bounded queues, and
GET /api/events streams SSE (always 200 text/event-stream, per-write chunked flush, heartbeat
by pop-timeout, Last-Event-ID replay/resume, shutdown sentinel) so that one real run-log line
appended to disk reaches a browser-shaped raw-socket client. Auth failure stays deliberately
terminal; graceful shutdown stays exit-0 even with open streams.

Purpose: SC2's transport half (LOGS-03) and the writer-agnostic mechanism that makes terminal/
watch relay the same feature as UI streaming (LOGS-04). Every later plan builds on this spine.

Output: `lib/spm_cache/web/events.rb` (Tailer + Broadcaster), `/api/events` route, the
Server#shutdown sentinel seam, three new spec files + the boot-helper raw-SSE extension.
</objective>
