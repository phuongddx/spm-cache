## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| trigger context → run bodies | tag input and event payloads cross into shell scripts; the only sanctioned crossing is env indirection |
| repo secrets → job | app credentials enter the runner and must never reach logs or other jobs |
| minted token → external tap repo | the installation token carries write access to exactly one repo |
| workflow → public tap content | the formula file edited in place is externally authored; edits must be pattern-validated |
| tarball URL → file system | the downloaded payload is untrusted until integrity-gated |
