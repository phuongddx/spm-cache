# Plan 15-03 — A8: `--rebuild` on the build verb (the forced-rebuild scope D-01 pins)

<planning_context>
phase: 15 — UI Build Controls
mode: standard (expansion — the CLI surface the tracer's scope table will select)
sources: 15-CONTEXT.md D-01 (verb-level scope: Build and Rebuild all; no per-package picker) and the Claude's-Discretion note; 15-UI-SPEC.md A8 (mechanism is planner territory; the argv row is how the user verifies which verb ran) and the Copywriting rows for the two buttons; 15-RESEARCH.md §Q3 'Scope must ride argv, not env' and Open Question 1 (recommendation: a --rebuild flag flipping the installer to include the cachemap hit set); ROADMAP Phase 15 SC1; REQUIREMENTS BLD-01
planner decision on Open Question 1: adopt the research recommendation — a --rebuild FLAG on the existing build verb, not a distinct verb and not a clean-then-build. Rationale: one gate to authorize, one option table to document, an argv row that reads as a reproducible terminal command, and no new destructive semantics (nothing is deleted; the same packages are rebuilt over).
</planning_context>

<downstream_consumer>
This plan is an executable prompt for /gsd-execute-phase. Plan 15-04's frozen scope table maps the POST value 'rebuild' onto the argv this plan ships; 15-05's `Rebuild all` button sends that value; 15-06's probe row 4 reads the resulting argv row in the identity card. Terminal users get the flag at the same time — it is public CLI surface from this commit.
</downstream_consumer>

<objective>
Give the dashboard's second button something real to call: a `--rebuild` flag on `spm-cache build`
that widens the build set from 'missed, plus hits whose cached slices are incomplete' to 'missed,
plus every cache hit', leaving the default path and every warning byte-identical.

Purpose: D-01's forced-rebuild scope as genuine, terminal-visible CLI surface (A8) rather than a
web-only behavior — so the identity card's argv row documents exactly what ran and a user can
reproduce it by hand.

Output: a constructor kwarg and one selection branch in the installer, the flag declaration and
pass-through on the command, one new spec file, and the README CLI Reference row.
</objective>
