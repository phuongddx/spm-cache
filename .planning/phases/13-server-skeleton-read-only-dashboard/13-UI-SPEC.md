## Design System

| Property | Value |
|----------|-------|
| Tool | none — hand-rolled CSS, zero build step, zero CDN (locked decision, 13-CONTEXT) |
| Preset | not applicable |
| Component library | none — vanilla ES modules, no framework (~300–400 LOC JS budget, locked decision) |
| Icon library | none — text glyphs only: `✓` / `!` / `✗` status markers and `↳` fix-hint prefix, reused verbatim from the doctor terminal vocabulary (`command/doctor.rb`) |

### Status colors (locked vocabulary)

Status colors reuse the doctor's `:ok` / `:warn` / `:fail` vocabulary and the existing cachemap-viz palette (`cachemap.js.template`, Material-500 family) — the one precedent the locked decision names:

| Status | Value | Terminal marker | Applies to |
|--------|-------|-----------------|------------|
| `:ok` | `#4CAF50` | `✓` | Doctor ok checks; graph/table `hit` nodes; fidelity `graph-pinned` / `host-pinned` |
| `:warn` | `#FF9800` | `!` | Doctor warn checks; graph/table `missed`; fidelity `resolution-incompatible` |
| `:fail` | `#F44336` | `✗` | Doctor failed checks |
| neutral | `#9E9E9E` | — | Graph/table `ignored`; fidelity `not-graph-pinned` |
| excluded | `#607D8B` | — | Graph/table `excluded` |
| plugin | `#3F51B5` | — | Graph/table `plugin` |
| macro | `#9C27B0` | — | Graph macro nodes (diamond shape, existing precedent); `◆` name prefix in the table |

Badges render as colored text on a 10%-alpha fill of the same status color, 4px/8px (xs/sm) padding, 4px radius — never a bare colored chip without text.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Refresh` — one per panel, top-right of the panel header. The doctor panel's CTA is `Run Doctor` (on-demand only — never auto-polled, locked decision) |
| Empty state heading (cache table) | `No cached packages yet` |
| Empty state body (cache table) | `Run spm-cache build to populate the cache, then Refresh.` |
| Empty state heading (doctor) | `Doctor has not run yet` |
| Empty state body (doctor) | `Select Run Doctor to check your environment.` |
| Empty state heading (graph) | `No dependency graph yet` |
| Empty state body (graph) | `Run spm-cache use to generate graph.json, then Refresh.` — LOCKED: names the generating command `spm-cache use`; the Refresh button in the panel header is the affordance |
| Error state (panel fetch failed) | `Couldn't load {panel}: {message}. Check that spm-cache web is still running, then Refresh.` |
| Error state (401/403 — token invalid) | `This page's access token is no longer valid. Restart spm-cache web and open the URL it prints.` (full-page state, replaces all panels) |
| Stale marker (doctor) | `Cached — generated at {HH:MM:SS}` — always visible whenever cached results are shown |
| Stale marker (state table) | `Updated {HH:MM:SS} · auto-refresh {N}s` in the panel header — never hidden, so polling lag is always honest |
| Stale marker (graph) | `Updated {MMM d, HH:MM} · generated by spm-cache use` — date-inclusive because `graph.json` can predate the server launch by days (time-only `{HH:MM:SS}` is safe only for the per-launch doctor cache) |
| Doctor summary line | `{N} ok · {N} warnings · {N} failures` — mirrors the CLI's `Summary:` line vocabulary |
| Destructive confirmation | none — Phase 13 ships zero destructive actions (read-only phase). Confirmation patterns arrive with Phase 15 (Build/Rebuild/Rollback) and are out of scope here |

Doctor check rows render `✓`/`!`/`✗` + check name + message, and a second line `↳ {fix_hint}` for every non-ok check that carries one — the exact format `command/doctor.rb` prints in the terminal. Fix hints are display-only; the web UI never executes them (research: "fix-hints as copy, never auto-execute").

## UI Considerations

Applicable state considerations resolved: 21 covered (explicit), 0 backstop, 0 unresolved — probe-run 2026-09-01 via ui-consideration-probe.cjs over elements E1–E5 (state table, doctor panel, graph canvas, token bootstrap, refresh controls); every category resolves to a contract line below

### Layout contract

Single page, no routing. 48px header bar (`#161B22`, border-bottom `#30363D`): page title `spm-cache` (Display) left; `127.0.0.1:{port}` (Label, mono, muted) right. Below: content column, max-width 1280px, centered, `lg` side padding. Panels stack in this order — 1. Cache State, 2. Doctor, 3. Dependency Graph — with `md` gaps. Each panel: `#161B22` background, 1px `#30363D` border, 8px radius, `md` padding; panel header row is title (Heading) left, stale-marker label + Refresh button right. The graph panel body is a fixed 480px-high canvas (`#0D1117` fill) with the status legend fixed inside its top-right corner (cachemap precedent) using 12px round swatches.

### Interaction contract

- **Token bootstrap (locked):** first `GET /` is redirected by the server to `/?token=<t>`. On load, JS moves the token from the query string into `sessionStorage`, calls `history.replaceState` to clean the URL to `/` **before first render**, and sends `X-SPM-Token` on every API call. The token value is never rendered in the DOM.
- **Refresh:** each panel's button disables itself while its fetch is in flight (label unchanged; no spinners). On success the panel body re-renders; on failure the body keeps its last good data and the error copy renders in the panel body area.
- **Auto-poll:** only the state table polls — `GET /api/state` every 5s (server-configurable; the header stamp always shows the effective interval). A failed poll never stops the loop and never blanks the table.
- **Run Doctor:** button disables with label `Running…` until the synchronous in-request run completes (checks shell out and can take seconds); results then render with the cached-at stamp.
- **Graph:** nodes only — no edges (edges are WEB2-01, deferred). Node color by status per the table above; macro packages render as diamonds. Nodes are not clickable in Phase 13 (no detail affordance is specified — adding one is Phase 16 scope).
