<objective>
Make the invariant Phase 6 establishes user-observable: a static `doctor` check that says
whether `spm-cache.lock` agrees with the host's `Package.resolved`, names every package that
disagrees, and needs no build.

Purpose: reconciliation is silent by design — it happens inside a `use` run. Without DIAG-01 a
user has no way to ask "is my lock telling the truth?" before spending a build on it. The check
also encodes the finding that makes this phase non-optional: on the reference project the lock
and the host graph share **zero** packages, so a comparison that only checks versions on the
intersection reports "0 drifted" for a maximally-stale lock.

Output: the `lock_graph_fidelity` check, its own spec file, the three existing `doctor_spec`
assertions updated in the same commit, and the false-premise comment in `UmbrellaGenerator.swift`
corrected to state the two preconditions revision-pinning actually requires.
</objective>
