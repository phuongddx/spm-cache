Establish graph authority end to end on the thinnest possible path, then complete the
locator that makes it non-vacuous.

Purpose: research finding A measured that `Dir.glob(File.join(root, "**/Package.resolved")).find`
— the idiom at all five call sites — returns a **stale nested** copy on the reference project,

makes ROADMAP success criterion 1 pass vacuously — both sides agreeing on the wrong file.
FID-06 therefore lands before FID-01's semantics, as a named change with its own regression
spec, not as a silent refactor.

Output: `Core::PackageResolved`, a proven canonical-preferring locator; all five glob sites
collapsed onto it; and a working end-to-end reconciliation slice for one drifted package.

## Interface contract created by Task 1 (consumed by Tasks 2-3 and by Plans 03-04)

`SPMCache::Core::PackageResolved` — `lib/spm_cache/core/package_resolved.rb`

| Member | Signature | Contract |
|---|---|---|
| `CANONICAL_RELATIVE_PATH` | `String` constant | `File.join('project.xcworkspace', 'xcshareddata', 'swiftpm', 'Package.resolved')` |
| `.locate` | `(project_path, parent_fallback: false) -> String \| nil` | Returns a path or `nil`. **Never raises.** Never `File.expand_path`es its argument — the returned path keeps the shape the caller's root had, because `command/use.rb` passes a relative root and prints/keys on the result. |
| `.pins` | `(path) -> Array<Hash>` | **Strict.** Propagates `JSON::ParserError` / `TypeError`. Preserves the current raise-loudly posture of `installer.rb` and `diff_detector.rb`. |
| `.pins_or_nil` | `(path) -> Array<Hash> \| nil` | **Tolerant.** `nil` means absent / unreadable / non-Hash root; `[]` means readable with zero pins. These two MUST stay distinguishable — conflating them turns "unreadable" into "empty graph", which combined with the D-01 drop rule erases the lock. |

Promoted to public on `SPMCache::Core::DiffDetector` by Task 1 (private instance delegators
retained so existing `send(:identity_key, …)`-style spec access keeps working):

| Member | Signature | Why public |
|---|---|---|
| `.identity_key` | `(url, path, name) -> String` (class method) | The reconciler must key on the same ssh/https/`.git`/`file://` equivalence the detector uses, or it drops packages that merely spell differently |
| `.normalize_url` | `(url) -> String` (class method) | Backing implementation of the above |
| `#live_packages` | `() -> Hash<String, Hash>` (public instance) | The authoritative live set: resolved pins **union** pbxproj package refs. `Package.resolved` never lists local/path packages, so this union — not resolved pins alone — is the only safe basis for membership decisions |
