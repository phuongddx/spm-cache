# Architecture

## Pattern

`spm-cache` is a **two-tier CLI tool**: a Ruby orchestrator (CLaide-based command tree) that coordinates SPM builds, Xcode project manipulation, and remote cache sync, delegating proxy-package code generation to a prebuilt Swift executable invoked via shell. It is stateless across runs except for a JSON lockfile (`spm-cache.lock`) snapshot of the SPM graph and a YAML config (`spm-cache.yml`).

## Layers (top → bottom)

1. **CLI layer** — `lib/spm_cache/command.rb` + `command/*.rb`. Root `Command < CLAide::Command`; default subcommand is `use`. Subcommands: `build`, `pkg` (`pkg/build`), `cache` (`cache/list`, `cache/clean`), `remote` (`remote/push`, `remote/pull`), `use`, `rollback`, `off`. `command/base.rb` defines `BaseOptions` (sdk, config, log_dir, merge_slices, library_evolution).
2. **Installer layer** — `lib/spm_cache/installer.rb` (578 LOC) orchestrates a run: `verify_projects!` → `detect_diff` → `recreate_dirs` → `ensure_config_file` → `sync_lockfile` → `prepare_proxy` → `gen_supporting_files` → `integrate_proxy_into_project` → `gen_cachemap_viz`. Variants: `Installer::Use`, `Installer::Build`, `Installer::Rollback`, with `Installer::Integration` mixins (`supporting_files`, `viz`, `descs`, `build`).
3. **SPM domain layer** — `lib/spm_cache/spm/`:
   - `build_pipeline.rb` (919 LOC, the heart) — per-destination xcframework build loop, scheme/module resolution, header/shim handling, forwarded-binary-target short-circuit
   - `build.rb` (417 LOC) — lower-level SPM build helpers
   - `pkg/proxy.rb` + `pkg/base.rb` — proxy `Package.swift` model
   - `desc/` — `swift package describe` parsing (Target/Product/Dep)
   - `xcframework/` (`xcframework.rb`, `slice.rb`, `metadata.rb`) — multi-slice framework assembly
   - `macro.rb`, `checkout_resolver.rb` — Swift Macro caching, checkout dir resolution
4. **Xcodeproj extension layer** — `lib/spm_cache/xcodeproj/` augments `Xcodeproj` objects to inject/remove the proxy package and rewire `XCSwiftPackageProductDependency` refs in `project.pbxproj`.
5. **Storage layer** — `lib/spm_cache/storage.rb` + `storage/{base,git,s3}.rb` — pluggable remote-cache backends.
6. **Core layer** — `lib/spm_cache/core/`: `config.rb` (Singleton), `lockfile.rb`, `diff_detector.rb`, `sh.rb`, `git.rb`, `parallel.rb`, `log.rb`, `live_log.rb`, `syntax/` (json/hash/yml/plist mixins), `system.rb`, `error.rb`, `cacheable.rb`, `hash.rb`.

## Core Mechanism: Proxy-Package Architecture

On `spm-cache use`, the tool (1) detects the SPM graph diff vs the last snapshot, (2) regenerates a **proxy package** — a Swift package that re-exports cached `.xcframework` binaries as binary targets while falling back to source for cache misses — and (3) edits the Xcode project so the app consumes the proxy instead of the original source packages. On cache hit, Xcode links the prebuilt binary; on miss, it compiles from source transparently. The proxy is generated by the Swift companion (`gen-proxy`) and umbrellas (`gen-umbrella`).

## Data Flow (typical `spm-cache use`)

```
bin/spm-cache → SPMCache::Main.run → Command::Use → Installer.new(project:, config:)
  → Installer#perform_install
      detect_diff   → DiffDetector(lockfile vs Package.resolved + pbxproj) → Diff (added/removed/updated)
      sync_lockfile → write fresh spm-cache.lock snapshot
      prepare_proxy → invoke Swift binary gen-proxy/gen-umbrella → proxy Package.swift + umbrellas
      gen_supporting_files → metadata, cachemap
      integrate_proxy_into_project → Xcodeproj edits project.pbxproj (purge orphans, wire proxy refs)
      gen_cachemap_viz → visualization data
```

## Fast Path

`Installer::Use` checks `@diff.empty?`; if the lockfile matches the live project, it skips proxy regeneration entirely and only ensures integration — the structural advantage over manually-synced manifest tools (noted in `installer.rb` and `diff_detector.rb`).

## Key Abstractions

| Abstraction | File | Role |
|---|---|---|
| `Installer` | `lib/spm_cache/installer.rb` | Orchestrates a full run |
| `SPM::BuildPipeline` | `lib/spm_cache/spm/build_pipeline.rb` | xcframework build loop |
| `SPM::Desc` / `Target` / `Product` | `lib/spm_cache/spm/desc/` | `swift package describe` model |
| `SPM::Xcframework` / `Slice` | `lib/spm_cache/spm/xcframework/` | Framework assembly & metadata |
| `SPM::Pkg::Proxy` | `lib/spm_cache/spm/pkg/proxy.rb` | Proxy Package.swift model |
| `Storage::GitStorage` / `S3Storage` | `lib/spm_cache/storage/` | Remote cache backends |
| `Core::Lockfile` | `lib/spm_cache/core/lockfile.rb` | SPM graph snapshot |
| `Core::DiffDetector` | `lib/spm_cache/core/diff_detector.rb` | Change detection |
| `Core::Config` | `lib/spm_cache/core/config.rb` | Singleton paths/options |
| `Core::Sh` | `lib/spm_cache/core/sh.rb` | Shell-out (Open3) |

## Entry Points

- `bin/spm-cache` — Ruby executable (`spec.executables`)
- `lib/spm_cache/main.rb` — `Main.run(argv)` → `Main.load_all` (requires all `.rb` under `lib/spm_cache/` sorted) → `Command.run(argv)`
- `tools/spm-cache-proxy` — Swift executable, subcommands `gen-proxy`, `gen-umbrella`, `resolve`
